weather app made for one of my Computer Science courses
this app displays weather information for a number of sample cities.

Features:
displays weather data for multiple cities
search/select different locations
can switch between celsius and fahrenheit
uses local JSON data
express server used to run the application

How to run:
Install Node.js
Open the project folder
Run npm install
Run npm start
The application runs on http://localhost:3000

Sample data:
Weather data is stored in sample.json
